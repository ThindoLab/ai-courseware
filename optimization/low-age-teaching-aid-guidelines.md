# 低龄教具优化指南（3-9岁）

**基于**：xueai.app 动画分析 + 低龄儿童教育设计调研（消防安全、数学可视化、儿童动画心印原则）

---

## 核心原则

### 1. 心印（Emotional Imprint）
- **可爱角色**：用圆润、放大眼睛/耳朵的动物角色（小兔子、小猴子、消防小熊）传递勇敢、善良、正向价值观。
- **情感连接**：故事以“帮助小动物/家人”开头，让孩子产生代入感和责任感。
- **重复强化**：关键安全动作或数学概念出现 3 次以上（不同场景重复）。

### 2. 具象 → 抽象递进
- 3-6岁：实物/emoji + 大图 + 简单选择
- 7-9岁：加入简单因果解释 + 小问题
- 10-12岁：可加入多步推理 + 自我反思

### 3. 游戏化 + 即时反馈
- 每一步都有“成功/失败”的即时视觉反馈（绿勾/红叉 + 表情）
- 错误不是惩罚，而是“再试一次”的机会（允许重选）

### 4. 内容丰富但不复杂
- 每屏信息控制在 1 个核心概念 + 1 个小问题
- 用“为什么”代替“是什么”（低龄更爱问为什么）

### 5. 安全/数学双轨
- 安全类：用可爱角色演示正确做法，避免恐怖画面
- 数学类：用“数一数”“排一排”“比一比”等动手操作感

---

## 具体优化动作（已应用到 kitchen-fire）

1. **角色化**：把“油锅着火”包装成“小熊的厨房着火了，我们来帮帮他！”
2. **重复**：安全动作（盖锅盖）出现 3 次不同场景
3. **游戏化**：加入“难度 Slider”让孩子自己选择挑战级别
4. **Bad/Good 切换**：让孩子看到“如果做错会怎样”（用可爱方式呈现，不吓人）
5. **情感结尾**：成功后出现“太棒了！你救了小熊！” + 星星奖励

---

## 验收标准（低龄版）

- [ ] 是否有可爱角色或拟人元素？
- [ ] 错误反馈是否温和且允许重试？
- [ ] 关键概念是否重复出现 ≥3 次？
- [ ] 画面是否简洁（每屏 ≤1 个核心问题）？
- [ ] 是否有即时视觉反馈（绿/红 + 表情）？
- [ ] 3-6岁版本是否以“帮助小动物”开头？
