# QA 多视角评分卡（v2）

> 教具质量评审的唯一权威标准。`reviewer` 子代理按本卡对每件教具打分，输出结构化 JSON，驱动 prompt 迭代。
> **场景**：中幼儿 / 家庭 / 教室 / 培训；**目的**：图解降难度、提理解与吸收；单文件离线。
> **质检必须充分理解 HTML**：走完交互路径，评估图解是否真的讲清关系——禁止只扫 grep / 只看有没有按钮。

## 〇、教学质量五硬核（先评，任一项 ≤2 或图解纯装饰 → fail）

| 代号 | 维度 | 问什么 | 证据要求 |
|------|------|--------|----------|
| Q1 | 理解难度 | 分龄是否合适？一次是否只推一个认知台阶？有无公式甩脸？ | 写出「孩子第一步会做什么」 |
| Q2 | 形象性 | 有无可感角色/物体/情境？ | 指出主形象与情境句 |
| Q3 | 图解清晰性 | 图是否承载关系/变化/差异？标签可读？ | 描述图中「变的是什么」 |
| Q4 | 逻辑一致性 | 步骤/因果/对错反馈是否自洽？ | 标出混乱点或写「路径自洽」 |
| Q5 | 过程动态性 | 该动是否真动（位移/生长/均分/对比）？ | 最小验收句是否成立 |

**深度理解段（评审 JSON 前必写）**：这个教具在教什么关系？孩子第一次点会看到什么→操作什么→应理解什么？

## 五大视角 × 评分维度（每项 1-5 分，3 为及格）

### 视角 A — 小学/幼儿学习者（孩子能不能独立玩懂）
- **A1 文字可读**：正文 ≥16px（3-6 岁 ≥24px），标题 ≥24px；无成人术语堆砌。
- **A2 触控可达**：按钮/滑块/热区 min-height ≥44px（3-6 岁 ≥64px，7-9 岁 ≥52px）；间距充足不误触。
- **A3 认知负荷**：单屏 1 个核心任务（3-6 岁）；操作→反馈≤1 步；不同时堆图/式/长解释。开局像没做完的事：材料打乱、先少后多、先演示再玩。一幕必须在当前视口做完，禁止下滑才见主操作。
- **A4 吸引力与一幕焦点**：一份教具一个 accent；主图是签名，其余安静。禁止紫粉双高亮、装饰 blob、标题下彩线、叠大字报+判决条。正反馈短而具体。无倒计时/排名/红叉羞辱。
- **A5 不卡壳（手能直接做）**：未选/无解/越界有温和提示；有重置。低龄主操作点物体本身，滑条只当次要；拖拽跟手且保留点选。3–7 岁有可跳过开场演示。底栏不得压住主图。

### 视角 B — 家长（能不能放心交给孩子）
- **B1 安全性**：无外链/无跳转/无外部请求；内容价值观正向；安全类教具的错误选项不可被模仿为脚本。
- **B2 通俗性**：家长能看懂孩子在练什么；标题/说明用日常话，不用教研黑话。
- **B3 独立可玩**：孩子能自己操作，不需家长全程盯；有「我怎么想」叙述帮孩子复述。
- **B4 离线可用**：双击即开，断网仍完整；不依赖任何账号/平台。

### 视角 C — 老师（能不能用于课堂讲解）
- **C1 教学目标**：首屏能看出「练什么」；不只是甩公式，有图解桥接；有核心认知动作（分组/比较/替换…）。
- **C2 知识准确**：数值/公式/定义 100% 正确（如鸡兔同笼 兔=(腿-2×头)/2）；单位明确；语言单复数/时态正确；安全建议符合官方行动原则。
- **C3 操作化**：至少 1 个交互改变知识变量并同步更新图/数/结论；假设法有三态、迁移有可点变式、语言有槽位预览。
- **C4 反馈教学性**：错误反馈含「确认行为→差异→下一步线索」，非「错了/再想想」；正确反馈有知识线索非纯表扬。
- **C5 可讲解性**：老师能借教具讲清思路；有变式/错例可课堂展开；白板触控友好。

### 视角 D — 培训机构（能不能交付/复用）
- **D1 专业度**：视觉干净不廉价；皮肤走 `--ink/#1e3a5f` `--accent/#2f6fbf`，圆角 16–18px；无错别字/半截文案/占位符。精致 ≠ 堆模块。
- **D2 完整性**：从开始到完成有闭环；有重置/下一题；多组例题；无半成品区。
- **D3 可复用**：换数字/场景能复用结构；有自检不产出次品；体积 ≤500KB。
- **D4 鲁棒性**：边界（0/极大/负/非整数）不崩；快速操作不卡死；动效不抢注意。

### 视角 E — 工程合规（硬性，不达标即不合格）
- **E1 单文件自包含**：无任何 http(s) 资源（img/script/link/image href/url()/外链字体）。
- **E2 原生实现**：JS 无外部库；图形用 emoji + 原生 SVG（circle/rect/line/path/polygon/text/use）；动画内联 @keyframes。
- **E3 结构完整**：有标题栏、主交互区、反馈/结论区、重置按钮；HTML 从 doctype 到 </html> 闭合。
- **E4 可访问性**：有 lang；有 aria-label 或语义标签；尊重 prefers-reduced-motion（或静态模式开关）。
- **E5 数值正确钩子**：关键计算用独立纯函数；无解情形有提示不抛错；整数/边界处理正确。

## 评分规则
- 总分 = 5 视角平均（满分 5）。
- **五硬核任一项 ≤2 或图解纯装饰 → fail**（优先于视角均分）。
- **任一 E 维度 = 1 分（硬伤）→ 整件不合格，必须修复后重评。**
- **C2 知识准确 <4 → 必须修复（知识错误零容忍）。**
- **mustFix 修复后必须全量复评**（五硬核 + 五视角），禁止只验修复点；total 低于该类型历史最佳视为回归。
- 评级：≥4.5 优秀 / ≥4.0 良好 / ≥3.5 合格 / <3.5 不合格。

## 必须输出 JSON（reviewer 严格按此结构返回）
```json
{
  "verdict": "excellent|good|pass|fail",
  "total": 4.3,
  "comprehension": {
    "teaches": "在教什么关系/步骤",
    "path": "看到什么 → 操作什么 → 应理解什么",
    "acceptance": "操作 X 后能看到 Y 过程"
  },
  "hardCore": { "Q1": 4, "Q2": 5, "Q3": 4, "Q4": 5, "Q5": 4 },
  "scores": { "A": 4.2, "B": 4.5, "C": 4.0, "D": 4.3, "E": 4.5 },
  "byDim": { "A1": 5, "A2": 4, "...": 0 },
  "mustFix": ["Q3: 主图只堆 emoji 不显示均分过程", "E1: 外链"],
  "shouldFix": ["A4: tada 过长"],
  "highlights": ["图解三态清晰"],
  "promptHints": ["system: 错误反馈必须含三段式"]
}
```
- `mustFix`：阻断项；`promptHints`：驱动下一轮 PE。
