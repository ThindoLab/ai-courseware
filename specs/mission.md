# Mission

## 我们在解决什么问题

家长和老师知道答案，但讲不清——不是缺知识，是缺可视化抓手。现有工具要么是静态 PPT（翻页没感觉），要么是整课平台（太重、太贵、打开就跑）。

我们做的事：**输入一句话知识点，输出一个能在白板或浏览器直接打开的可交互单文件 HTML 教具。**

---

## 服务谁

| 用户 | 场景 | 他们要什么 |
|------|------|-----------|
| 家长 / 老师 | 晚间辅导、白板授课 | 打开即用，一点就懂，不用装软件 |
| 教育机构 | 试听 / 宣传互动材料 | 快速出可交互页，电子白板即用 |
| AI 副业创作者 | 制作 Skill + 教具内容 | 低成本出货，拿去小红书 / 微店外部售卖 |

核心判断：**系统提供框架，创作者补长尾内容。** 前期不做平台，做工具。MVP 优先服务家长 / 老师 / 创作者；教育机构留待扩展期。

---

## 成功长什么样

创作者输入一个知识点，2 分钟内拿到一个自包含 HTML，老师当晚在电子白板上用了——这就算成了。

更具体的可验收标准：
- 3 类交互模板（参数图解 / 选择分支 / 拖拽槽位）可稳定生成
- 数学样例 ≥ 8 个，契约校验全绿
- 单次生成 ≤ 2 分钟（抽样验证）
- 断网下核心交互仍可用
- 至少一次平板 / 白板触控验证通过

---

## 明确不做的事

- 整课多智能体课堂（不是 OpenMAIC）
- PPT / PPTX 生成
- 平台内账号、付费墙、交易市场（前期）
- TTS / ASR / 课堂回放
- 3D / 在线编程沙箱

---

## 约束与边界

**LLM 不自由写 HTML 骨架。** 模型只填内容 JSON，由注入器写入固定模板。这是核心质量门禁，不得绕过。

输出格式前期只做单文件 HTML，不做其他格式中台。

知识来源按模块管控：学习辅导优先本地教材，不允许全网自由抓取。
