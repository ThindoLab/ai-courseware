# 人物库使用手册（写手 / 质检）

人物不现场画，也不调 `cast_image`。从本目录闭集里**选型**，和清华 OpenMAIC 一样：模型只决定「谁上场」，脸已经画好。

资源：`pi/assets/cast/openmaic/*.svg`。清单：`roster.json`。许可：`NOTICE.md`。

## 写手怎么用

1. 写前 `read` 本文（或调 `cast_roster` 不带 id，看目录）。
2. 按题意选 **1 种**语言：本库扁平头像 / 豆人 / 火柴人。有名字的人用本库，不要混。
3. `cast_roster({ id: "teacher" })`（或中文「老师」）。不要手写五官。  
   动物/食物/车/童话符号：`cast_search({ query: "牛" })` → `cast_asset({ id: "noto:cow-face" })`，占位 `data-cast-pack`。目录见 `pi/assets/cast/README.md`。
4. HTML 只放空组，宿主会填 SVG：

```html
<g data-cast-roster="explorer" transform="translate(80 40) scale(0.42)"></g>
```

5. 同一人各幕同一 `id`。走动只改外层 `transform`，禁止改内部 path。
6. 正戏 `<use href="#explorer">` 克隆已填组。禁止运行时空 `data-cast-roster`。
7. 动物、灯、桥走 `cast_icon`。过程（相向走、搬格）走 `cast_svg` / 图解代码。

| 题里的人 | 用这个 id |
|----------|-----------|
| 老师 / 家长 / 王母 | `teacher`（第二大人 `assistant`） |
| 默认小孩 / 同学 | `student1` |
| 第二、第三个孩子 | `student2` / `student3` |
| 赶路、行程、牛郎 | `explorer` |
| 文静、织女 | `student3` 或 `scholar` |
| 嫦娥、幻想 | `dreamer` |
| 提问 / 想一想 | `curious` / `thinker` |
| 错例捣蛋 | `clown`（安全题不要用他当正确示范） |

库里没有的古装细节：仍用最接近的头像 + 道具图标（帽、筐、月），**不要**为了像而去生图。

## 质检查什么

- 故事点了人名（牛郎/织女/王母/悟空/哪吒/嫦娥等），却仍是自写 `person`/`bean`/`maggie`，且没有 `data-cast-roster` / 本库头像 / 图标人 → `cast-quality` error。
- 一份教具里火柴人、豆人、本库头像混用 → mustFix。
- 占位写了但运行时还在空 `data-cast-roster` 上变姿势 → mustFix。
- 用了 `clown` 当安全正确示范 → shouldFix。
- 不要再要求写手调 `cast_image`（GPT Image 2 未注入）。
