# ima/

账号知识库检索。教练先读目录再决定搜不搜，写手不调 `ima_search`。

## 一层：文件

| 文件 | 给人看？ | 作用 |
|------|----------|------|
| `检索指南.md` | 是 | 何时搜、怎么搜、和 web / 本地切片怎么分工 |
| `知识库目录.md` | 是 | 脚本生成：简介、类型、范围、何时搜 |
| `allowlist.txt` | 是 | 非空则只允许这些库名；空 = 不限制 |
| `catalog.json` | 否 | 工具用（含 kb_id），gitignored |

## 二层：更新

```
npm run ima:sync          # 拉一次目录
npm run ima:sync:hourly   # 本机定时
```

同步失败保留旧目录。文首「上次成功同步」是上次成功时间。

## 三层：细则

用法只认 `检索指南.md`。教练排程见 `../教练.md` 第 2 步。
