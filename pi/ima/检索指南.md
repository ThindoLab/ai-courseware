# ima 检索指南

给教练用。写手不要自己调 `ima_search`。

## 判断（先读目录，再决定）

1. `read` `pi/ima/知识库目录.md`。
2. 用户原句是否对得上某库的**名称 / 简介 / 内容范围 / 何时搜**。
3. 对得上 → `ima_search`；对不上 → **跳过**，禁止「保险起见搜一下」。
4. 已 `use_sample` 交付精品 → 本场不搜 ima。

中幼儿影子、均分苹果、切披萨等目录对不上的，走图解 + 本地 `knowledge_search`，不要搜「考公」「连麦案例」。

## 怎么搜

- 参数：`knowledge_base` = **库名**（与目录标题一致），不要内部 id。
- `query` 用知识点词，可在同一句里写多个词，空格分开：`申论 格子纸`。
- 一次调用只打一座库。官方接口每次一个 query 字符串，不是关键词数组。
- 次数教练自定。多角度再调。本场建议最多 **5 次**，避免把生成超时搜穿。
- 没有 ima「问答」接口。搜到的是标题 + 摘要，你自己组织给写手。

## 和 `web_search` 的分工

| 工具 | 搜什么 |
|------|--------|
| `ima_search` | 你账号里的知识库，先读目录再决定 |
| `web_search` | 公开网页。目录对不上、本地切片也没有时再用 |
| `knowledge_search` | 仓库 `knowledge/extracted/`，写手最多一次 |

## 片段怎么用

- 当事实交给写手，不要整篇贴进 HTML。
- 摘要为空时，至少把标题当线索；不要假装搜到了正文。
- 网络/凭证失败：当没搜到，继续本地知识或直接写。禁止用旧 `output/` 充数。

## 白名单

`allowlist.txt` 每行一个库名。非空则 `ima_search` 只允许这些库。空文件 = 不限制（仍靠你判断）。

教具场景建议只放教学相关库，私人/订阅库不要写进去。

## 更新目录

| 方式 | 命令 |
|------|------|
| 人工 | 仓库根目录 `npm run ima:sync` |
| 每小时 | `npm run ima:sync:hourly` 安装本机 launchd（见 `scripts/ima-sync.plist.example`） |

同步失败会保留旧目录；文首「上次成功同步」是上次成功时间。`:3000` 里不跑同步。

凭证：`~/.config/ima/client_id` + `api_key`，或环境变量 `IMA_OPENAPI_CLIENTID` / `IMA_OPENAPI_APIKEY`。申请：https://ima.qq.com/agent-interface
