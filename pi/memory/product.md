# 产品记忆

- 人群：中幼儿、家庭辅导、教室白板、培训巩固。  
- 目的：图解降低理解难度，不是炫技。  
- 五硬核：理解难度、形象性、图解清晰、逻辑一致、过程动态。  
- 本阶段用户只说一句话；模块与类型由流程推断，不做成表单。
- 错误分三类：安全 / 概念 / 操作。安全类选错必须有一段错误说明（会怎样、该怎么做），不能一笔带过。收尾可有 1 个举一反三。
- 学前开局：可跳过演示、材料打乱、拖要跟手、点物体不靠滑条当主控、配对先少后多、比长短玩时默认对齐、主图不出屏。
