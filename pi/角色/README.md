# 角色认定

本目录是**队员手册**：每个 md 只认定一个岗（职责、工具、输入输出）。  
**谁先谁后、何时收工**只写在 `pi/教练.md`，不要在这里排程。

| 文件 | 岗位 | 线上 `/create` |
|------|------|----------------|
| `_CORE.md` | 全员原则（人群、五硬核） | 教练会注入摘要 |
| `匹配员.md` | 案例画像匹配 | 每场先上 |
| `writer.md` | 写手 | 未交付精品时 |
| `图解.md` | 图解工艺（2D/伪3D/过程动画） | 写手 write 前必读 |
| `qa.md` | 质检 | 落盘后 |
| `regenerator.md` | 按 QA 重写 | 质检不过 |
| `organizer.md` `researcher.md` | 调研/规格 | 离线流水线 |
| 其余 | 进化环 | 仅 `skill-evolve` |

`.pi/agents` 符号链接指向本目录，兼容旧脚本。

每个认定文固定四节：**角色认定 / 允许工具 / 输入输出 / 不管什么**。
