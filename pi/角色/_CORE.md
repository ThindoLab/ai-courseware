## 1. 场景与人群

| 场景 | 人群 | 要什么 |

| 中幼儿 | 3–8 岁 | 形象、少字、大按钮、一步一反馈 |

## 2. 原始目的（最高优先级）

> **用图解降低学习难度，提升理解与知识吸收。**  
> 不是堆交互、不是炫技、不是复述文档旧题。  
> 交付：一句话知识点 → 可交互、离线、单文件 HTML 原子教具。

## 3. 教学质量五硬核（质检第一关）

1. **理解难度** — 分龄降阶；一次一个认知台阶；禁公式甩脸  
2. **形象性** — 可感角色/物体/情境  
3. **图解清晰性** — 图承载关系/变化/差异，非装饰  
4. **逻辑一致性** — 步骤、因果、反馈自洽  
5. **过程动态性** — 该动则真动（位移/生长/均分/对比）

任一项严重不足 → fail。图解纯装饰 → fail。

## 3.1 错误分类 · 反例 · 举一反三

选错以后要说明，但说明的篇幅跟**错误类型**走，不抢主题。

| 类型 | 选错意味着 | 错误说明要写到哪 |
|------|------------|------------------|
| **安全** | 这么做会受伤/遇险 | **必须写满**：错在哪、会怎样（图）、马上该怎么做。禁止「这样不安全」一笔带过。选项仍用疑问式/第三人称，不可写成可照做的步骤 |
| **概念** | 想错了、易混 | 对照对例，点出差在哪一处 |
| **操作** | 点滑了、填错格 | 短反馈 + 允许重选即可 |

安全知识（油锅、过马路、敲门、溺水等）里，孩子点到的错选项一律按上表「安全」来写说明。主线仍是正确做法，错误说明服务主题，不另开一课。

- **举一反三**：收工前给 **1 个同构变式**（换数 / 换物 / 换场景）。骨架不变，孩子能自己迁。不要新概念，不要做成做不完的死题。
- **死题零容忍**：选项/候选必须覆盖正确答案（表盘 10 点就不能全是 9 点；空位「月」候选里必须有「月」）。称重、票数、凑十必须自洽，孩子按规则能做对。
- **关卡与收束**：多关必须有「下一关」。全部完成后出祝贺/完成页（对照 `there-be`、`brush-steps`），不要无声回到第一关。可提供「再玩一次」，但必须是孩子点了才重来。

## 3.2 学前开局（3–7 岁）

开局要像「还没做完的事」，用手直接做，先看懂再加难。不要靠会被一屏压缩藏掉的长旁白。

- **开场演示**：进门用可跳过 overlay **真演一遍**（角色/物要位移或入槽，约 8–12 秒）。禁止只贴一张静图当「看一遍」。点「看一遍」必须播这段。`prefers-reduced-motion` 时只出静帧 + 一句。不要循环挡主图。
- **乱着开始**：分类 / 排序题禁止按答案排好再让孩子点。打乱底部材料。
- **拖得见且可点**：拖拽必须跟手（pointermove 改位置）。点选入位仍要保留，两种都能用。
- **点物体，不点抽象控件**：低龄主操作是点星星/积木/条子。滑条与「+ −」只能当次要，不能当唯一控数方式。凑十要能一颗颗补满十格，不要写成死板的 9+1 只许拖一颗。
- **先少后多**：记忆配对等负荷题第一关先少对（如 3 对），过关再加。找零等生活题先少面额、少步数。
- **比长短**：演示里先演「不对齐会看错」；玩的时候默认已对齐。对齐知识点用一键对照，不要让孩子一进来就和歪条较劲。
- **图必须在屏内居中**：主图（十框、条子、牌面、彩灯）不得被一屏适配拉出视口，**同组图标不得互相覆盖**。
- **选中要看得见**：点卡片/色块后高亮选中，不要先翻没再消失。对错要立刻有提示。

## 4. 探索纪律

每轮至少：
1. 反向验证：铁律是否在样例中真落地  
2. 用户走查：7 岁第一次点 / 家长 30 秒能否讲清  
3. 多样性：避免连续重复同一壳子与知识点  
4. 深度读 HTML：写清「教什么 → 点什么 → 应懂什么」

## 5. 验证与落库

- 禁止「我觉得 OK」；须有路径/验收句/评分  
- mustFix 后全量复评  
- 半成品不得进 `samples/` / `output/best/`
