- 输出：`qa_check` 结果 + 五硬核是否挂；列出 mustFix

## 不管什么

## 必须检查
0. **脚本能跑**：`script-syntax` 不过 = 整页死。  
   **出图质量**：故事人物仍是手画 `person`/`bean`/`maggie` 且无 `data-cast-roster` / `data-cast-pack` / 图标人 → `cast-quality` error。写手必须 `cast_roster`（人）或 `cast_search`+`cast_asset`（动物/物）。不要要求 `cast_image`。空着 `data-cast-roster`/`data-cast-pack` 没被宿主填上 → mustFix。
1. **动态过程**：该动的是否真的动了？（静止伪动画、只改数字、只 scale → mustFix）。对照 `pi/角色/图解.md`：要有 SVG 属性变化或 CSS 3D 翻转或 Canvas 粒子。
2. **低龄心印**：故事/角色/具象/温和错误
3. **教学正确性**：知识点无误
4. **交互**：错误可重选、触控、无外链
5. **观感与体验**（见下节；只写「不紫」不够）
6. **安全类错误说明**：安全题每个危险选项若只有「不对/不安全」而无「会怎样 + 该怎么做」（最好有后果图）→ mustFix
7. **举一反三**：变式必须同构且题面能做对；做成新概念或死题 → mustFix。完全没有且主题适合迁移 → shouldFix
8. **学前开局**：3–7 岁题若无**真动**开场演示（静图冒充演示）、分类已排好答案、只能滑条控数、主图出屏或图标互叠、配对一上来过多张 → mustFix
9. **死题 / 卡死 / 揭晓被盖**：选项或候选盖不住正确答案、空位与候选对不上、多关做完没有「下一关」、通关后无声回到第一关 → mustFix。`qa_check` 对 `ux-next` / `ux-end` / `ux-end-loop` / `playable-dead` / 缺 `aid-contract` / **`reveal-cover`** 记 **error**（passed=false），不是 warn。
10. **选中与收束**：点中无高亮、对错无提示、通关无祝贺页（对照 `there-be`）→ mustFix。安全错若只有字没有后果图 → 仍按第 6 条 mustFix
11. **保留清单**：`pi/memory/keep.md` 里锁住的篇，过检失败也**不要**整页重写；只报缺口。现库是基线，加严只拦新生成。

## 观感与体验（孩子第一次点，不是海报打分）

先走一遍：打开 → 第一眼看到什么 → 手点哪里 → 要不要下滑 / 先读长旁白才知道干什么。对照 `图解.md` 展示纪律。用户反馈背后的一致诉求是：**开局像没做完的事，用手直接做，一屏看完，先懂再加难。**

### mustFix（体验挂了就重写）

- **一幕看不完**：未锁 `100dvh` + `overflow:hidden`，或主图/主操作被挤出视口、必须下滑才能做题。矮屏应先藏旁白，不要把整页缩成邮票。
- **主图不在场**：主图歪出屏幕、贴在视口外、或被底栏 `position:absolute; bottom:0` 压住。主图须在剩余高度里居中长大。
- **开局不像任务**：学前分类/排序已按答案排好；待投放物叠死在一角或宽高塌掉，孩子看不见能拖的东西；记忆配对第一关牌过多；比长短玩时默认歪着较劲。
- **手够不着概念**：低龄主操作只有滑条 / `+ −`，不能点格子、条子、积木本身。拖拽不跟手且没有点选兜底。拖着的物被槽/筐底色盖住，或被父级裁掉 → mustFix。
- **开场挡路或假演示**：3–7 岁没有可跳过演示，或「看一遍」没反应 / 只是静图。演示循环挡主图、不能跳过同样 mustFix。演示和正式玩不是同一套主图、或演示揭示的答案违背本场规律 → mustFix。
- **死题或关卡卡死**：选项不含正确答案；空位在候选里没有；**每一关**（含第一关）完没有下一关；通关自动循环回第一关且无祝贺。选对后「下一步」被一屏裁掉、孩子看不见后续 → mustFix。
- **填入被盖 / 揭晓章盖住答案**：问号/虚线提示在答案落入后仍压住内容 → mustFix。刚补上的灯/字/物被不透明方牌或大对号盖住（含开场演示）→ mustFix。对了只能镂空环或把对号放旁边。`qa_check` `reveal-cover` 过不了就不能交。
- **主槽塌掉**：车厢/格子/槽位没有最小宽高、进场看不见主操作物 → mustFix。
- **图色和判定色打架**：图/emoji 主色与答案色明显不是同一色（红车判蓝）→ mustFix。
- **假举一反三**：变式换了一套孩子认不出的编码（颜色改成线框形状、数量改成全新符号）→ mustFix。只允许换数 / 换色 / 换物，骨架不变。
- **选中看不见**：点卡片/块后翻没或无高亮；拖到位后完成/失败都没提示。
- **装饰抢戏**：紫粉双高亮、装饰 blob / 渐变光晕、标题下一条 accent 彩线、同一幕再叠大字报 + 判决条 + CTA。一份教具只留一个 `--accent`。
- **文案不是界面**：可点控件写「提交」；错误只闪「错了」不说怎么改；页眉、钩子、教练旁白互相翻译同一句。

### shouldFix（不因此单独 fail）

- 正文/选项居中挤成一坨（标题可居中，说明与步骤左对齐）
- 并列选项套了假 01/02/03
- 缺「我会说」；或「我会说」做成挡主图的长文（矮屏应可藏）
- 编号徽章、描边风格同幕不统一；引线穿过主图关键部位

对抗反思：不要为了「更好看」拆掉已经清楚的主图、安全红线、一屏结构。观感分服务体验，不另立一套海报审美。
