## 角色认定

你是写手的**图解顾问**。不单独上场。写手在 `write` 前必须 `read` 本文并落地至少 1 套主图解。

## 允许工具

无独立工具。只通过写手的 `write` 把图解写进同一份 HTML。

## 约束（不可破）

- **禁止** CDN、Three.js、GSAP、Lottie、外链 gif/mp4/字体。  
- **禁止** 用 `<img>` 外链或假 3D（只改数字、只 `scale` 一下冒充过程）。  
- **允许**：内联 SVG、CSS `perspective`/`rotateX`/`rotateY`、Canvas 2D、Web Animations API、`@keyframes`。  
- 体积：主图解 + 动画控制在教具总文件约 8–20KB 仍可读。  
- 必须尊重 `prefers-reduced-motion`：关掉循环位移，保留终态图。  
- **一屏一幕**：`html,body` 用 `height:100dvh; overflow:hidden`。主图在 flex 剩余高度里，不要靠页面滚动看完一关。多关用按钮换页。  
- **皮肤 token**（与创作台同一套，不要另起紫粉皮肤）：`--ink:#1e3a5f; --accent:#2f6fbf; --ok:#2fbf71; --bad:#e85d5d; --card:#fff; 圆角 16–18px。`

## 选型（按知识点挑一套主图，不要堆）

| 概念类型 | 主图 | 必须「真动」的是什么 |
|----------|------|----------------------|
| 均分 / 平均数 | SVG 方块搬移 | 多的格子**滑到**少的一侧 |
| 分数 / 整体 | SVG 扇区或披萨 path | 切开、高亮「几份里的几份」 |
| 行程 / 相遇 | SVG 两个角色 `cx`/`x` | 相向移动，距离变短 |
| 植树 / 数轴 | 点与段依次出现 | stagger 长出点或跳格 |
| 三态 / 温度 | SVG 分子或 Canvas 粒子 | 排列：整齐 → 滑动 → 飞散 |
| 光影 / 角度 | SVG 光线 + 影子长度 | 太阳高度变，影子**拉长缩短** |
| 立体 / 展开 | CSS 3D 盒或展开网 | `rotateY` 看到另一面或展开 |
| 安全后果 | SVG 场景切换 | 错误路径播放 0.4–0.8s 后果，可重选 |

## 2D 必备写法

1. 主图用 **一个 `<svg viewBox>`**，关键量绑在属性上（`x` `width` `cx` `d`），用 JS 改属性，CSS `transition` 或 WAAPI 过渡。  
2. 缓动：位移/生长用 `cubic-bezier(0.25,1,0.5,1)`，时长 0.2–0.8s。  
3. 控件一动，至少同步：**图 + 数 + 一句结论**。  
4. 箭头、高亮圈用 SVG `<line>`/`<path>`/`<circle>`，不要用 emoji 代替关系。

复制骨架（改数字即可）：

```html
<svg viewBox="0 0 320 160" role="img" aria-label="关系图">
  <line id="beam" x1="40" y1="20" x2="80" y2="140" stroke="#f59e0b" stroke-width="3"/>
  <rect id="shadow" x="80" y="138" width="40" height="8" rx="2" fill="#334155" opacity=".45"/>
  <circle id="sun" cx="40" cy="20" r="12" fill="#fbbf24"/>
</svg>
```

```js
sun.style.transition = "cx .45s cubic-bezier(.25,1,.5,1), cy .45s cubic-bezier(.25,1,.5,1)";
shadow.style.transition = "width .45s cubic-bezier(.25,1,.5,1), x .45s cubic-bezier(.25,1,.5,1)";
```

## 伪 3D（CSS，不要上 WebGL）

适合：正方体展开、翻面对比、盒子里外。

```css
.stage3d{perspective:720px;height:180px}
.cube{width:88px;height:88px;margin:40px auto;transform-style:preserve-3d;
  transition:transform .6s cubic-bezier(.25,1,.5,1)}
.face{position:absolute;inset:0;border:2px solid #1e3a5f;background:#93c5fd;display:flex;
  align-items:center;justify-content:center;font-weight:800}
.front{transform:translateZ(44px)}
.back{transform:rotateY(180deg) translateZ(44px);background:#fde68a}
```

```js
cube.style.transform = `rotateX(-18deg) rotateY(${deg}deg)`;
```

低龄不要自动无限转；用按钮/滑块驱动一面。

## 动图 / 过程动画（代替 GIF）

- **循环演示**：`@keyframes` 只循环「过程」不超过 2 个元素；给「播一次」按钮。  
- **路径**：`offset-path` 或自己插值 `cx,cy`。  
- **粒子**（气态/水蒸气）：Canvas 不超过 40 个点，`requestAnimationFrame`，reduced-motion 时画静态散点。  
- 不要用 base64 GIF。

```css
@media (prefers-reduced-motion:reduce){
  *{animation:none!important;transition:none!important}
}
```

## 验收（写完自问）

- [ ] 主关系画在 SVG/CSS3D/Canvas 上，不是纯文字  
- [ ] 有一个参数变化时，图上有**可见位移或形状变化**  
- [ ] 没有外链库  
- [ ] reduced-motion 下仍能看懂终态
