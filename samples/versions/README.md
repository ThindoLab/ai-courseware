# 样例版本

每个 slug 一个目录。`v1` 最早，数字越大越新。当前稿同时在 `samples/<slug>.html`。

打开历史：`http://127.0.0.1:3001/samples/versions/<slug>/v1.html`

清单见 [manifest.json](manifest.json)。反馈记录必须写 `版本：vN`。  
分批迭代见 [../分析/_迭代.md](../分析/_迭代.md)：每轮记 **版本 / 反馈 / 检查 / 优化**。页头有 `aid-iteration`（如 R2）。  
大纲与注意事项：[../分析/_迭代须知.md](../分析/_迭代须知.md)。
