# 选择分支教具创作（直出 HTML）

> 本 skill 是 **branch-story 类型专属**指导。通用分龄/方法论见系统注入的通用规范。两者叠加生效。

## 你产出什么
一个单文件 HTML 选择分支教具，用 `write` 工具写入输出路径。不输出 JSON、不调模板渲染。

## 类型定位
情境决策类：童话、寓言、安全（消防/防溺水/防拐/数字安全）、生活选择。
**核心**：情境 -> 决策点 -> 后果反馈 -> 求助/修复。孩子做选择，看到后果，学会正确行动。

## 必须有
- 情境描述卡（emoji + SVG 场景，如厨房🔥、水池🌊）
- ≥3 个决策节点，每节点 2-3 个选择按钮（大号、图标）
- 每个选择显示后果：正确=绿色+tada+⭐+肯定文案；错误=橙色/红色警示+wobble+说明正确做法
- 正确路径可达 success 终态；错误路径有反馈非死胡同
- ↻ 重新开始；可选进度（已通过几关）

## 安全类红线（极重要）
- 错误选项必须配「禁用/警示」视觉，反馈**先说安全动作再解释错误原因**
- 错误选项**绝不可变成「可模仿的脚本」**：不要把错误做法写成可照做的步骤序列。**严禁祈使句/命令式**：
  - ❌ 「趍紧用水浇灭」「拿毛巾去拍打」「掀开锅盖看看」（祈使句，儿童可直接模仿）
  - ✅ 「有人建议用水浇灭」「拿毛巾拍打试试会怎样？」「掀开盖子看一眼行吗？」（第三人称/疑问式，拉开行动距离）
  - **所有错误选项统一疑问式（…会怎样？/…行吗？）或第三人称归因（有人说…），禁止陈述式行动描述**
  - 反馈先说「赶快停下，不要这样做」再解释危险再给正确做法
- 分龄安全内容：
  - 3-6 岁：只学「离开、叫大人、打 119/110」
  - 7-9 岁：识别可疑请求并说理由
  - 10-12 岁：隐私 / 旁观者 / 长期后果
- 安全建议须符合官方行动原则且**完整覆盖行动链**：消防须含「低姿 / 捂口鼻 / 不乘电梯 / **火大灭不了打 119 报警** / 离开关门」；防溺水须含「不擅自下水 / 呼救 / 找漂浮物 / **打 110 或 119**（119 水上救援直拨号）」。不得遗漏报警环节。

## 分支结构
- JS 维护 `nodes` 对象：`{id, text, choices:[{text, next, correct, feedback}]}`
- **答对后立即置 `answered` 锁并禁用同节点所有选项**（含多正确选项节点），防止快速连点 schedule 多次 render 跳转混乱
- 终态节点 `ending: success/fail/neutral`
- 每个非终态节点至少 1 出口，**无死胡同**
- 错误选择给即时后果反馈，可回退或重选

## 错误分型

每个 choice 标 `errKind: "safety" | "concept" | "action"`（安全题的危险选项一律 `safety`）。

| errKind | 选错后 |
|---------|--------|
| **safety** | 必须出一段错误说明：①点了什么 ②为什么危险、会怎样 ③马上该怎么做。配本选项专属后果 SVG。禁止一句「这样不安全」带过，禁止多个错选项共用同一句反馈 |
| concept | 对照对例，点出差在哪 |
| action | 短反馈 + 重选 |

## 反馈教学性（三段式）
- 错误反馈三段式：**确认行为**（「你选了用水浇油火」）-> **标差异/危险**（「油比水轻，水会让火溅开变大」）-> **给下一步**（「应该盖锅盖 / 关火 / 逃跑报警」）
- **safety** 类把三段都写全，可略长（3–5 句），仍先说「停下，不要这样做」
- 正确反馈：肯定 + 为什么对 + 下一步线索
- **禁止**「错了 / 再想想 / 真棒」无信息反馈

## 错误后果可视化 + 深度引导（重要）
错误选择后，不仅给文字三段式，还要**弹出危害后果 SVG 场景图**（不只是 emoji）：
- **必须用原生 SVG 画错误后果场景**：如油锅加水->画锅+水滴+多团溅开的火苗 SVG；跳下水救人->画水面+下沉的人影 SVG；跟陌生人走->画迷路场景 SVG
- 后果图弹层（如 `.consequence` 区）显示 SVG 场景 + 三段式文字，同屏出现，让孩子直观看到「为什么不能这样做」
- SVG 示例（油锅加水火溅开）：
```svg
<svg viewBox="0 0 200 120"><!-- 锅 --><ellipse cx="100" cy="90" rx="60" ry="12" fill="#444"/><!-- 水 --><circle cx="100" cy="60" r="6" fill="#60a5fa"/><!-- 溅开火 --><path d="M70 80 Q60 50 75 40" stroke="#f59e0b" stroke-width="4" fill="none"/><path d="M100 70 Q95 35 110 25" stroke="#ef4444" stroke-width="5" fill="none"/><path d="M130 80 Q140 50 125 40" stroke="#f59e0b" stroke-width="4" fill="none"/><text x="100" y="115" text-anchor="middle" font-size="14" fill="#dc2626">水让火溅开变大！</text></svg>
```
- 然后**允许重选**：错误选项禁用并加警示样式，但保留正确项可选，孩子可继续选到正确答案
- 一步步深度引导：第一次错->后果 SVG+三段式线索；仍错->更明确线索+示范正确思路；直到选对。错误是学习起点，不是终点
- 禁止「错了就卡住 / 直接跳过 / 只给文字无 SVG 后果图」

## branch-story 验收 checklist（生成后 read 回读逐条确认）
- [ ] ≥3 决策节点，正确路径可达 success
- [ ] 每选择有后果反馈（正确/错误视觉区分）
- [ ] 错误选项**不可模仿为脚本**（安全红线）
- [ ] 错误反馈三段式（确认 -> 差异 -> 下一步）
- [ ] 安全类错选项各有一段错误说明 + 专属后果图，无一笔带过
- [ ] ↻ 重新开始可用；触控 ≥44px
- [ ] 分龄安全内容正确；情境图 emoji+SVG
- [ ] 无外链、原生 JS 无库、单文件

## 常见失败
错误选项变可模仿脚本；**错误选项写成祈使句**（如「用水浇灭！」）→ 一律改疑问式/第三人称；反馈只说「错了」；无 SVG 后果图只有文字；答对后 <3s 自动跳转清空；无重新开始；分支死胡同；安全行动链缺 119/110；不分龄把复杂判断给学龄前。

## 课堂/生活常规也可做 branch-story
不限于安全：举手发言、排队、借还物品等教室/家庭规则，同样用「情境→选择→后果图→修复」降低社交理解难度。
