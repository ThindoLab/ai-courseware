# 拖拽槽位教具创作（直出 HTML）

> 本 skill 是 **drag-slot 类型专属**指导。通用分龄/方法论见系统注入的通用规范。两者叠加生效。

## 你产出什么
一个单文件 HTML 拖拽槽位教具，用 `write` 工具写入输出路径。不输出 JSON、不调模板渲染。

## 类型定位
组合/排序类：英语句型（there be / 单复数 / 时态）、拼音组词、步骤排序、词汇搭配。
**核心**：可见槽位 + 可选词块 + 实时句子预览 + 即时判定。孩子拖词入位，看句子成不成立。

## 必须有
- 槽位区（slots）：空位，可拖入 token
- 词块区（tokens）：可拖词块，含**正确项 + 干扰项**
- 实时预览：拖入即拼成**完整结果**显示（拼音直接拼成音节 `ma` 而非 `m_a`；句子拼成完整句），强化「拼成一个整体」的认知
- 即时判定：对=绿色+bounceIn+⭐；错=红色+wobble+提示
- 检查按钮 + ↻ 重置；多组例题 / 下一题
- 触控：token、slot 都 ≥44px，用 pointerdown/move/up 兼容触摸

## 句型结构可视化
- 把句子拆成语义槽位：谁 / 做什么 / 在哪里 / 单复数（there be）等
- 给词库 token（主语 / 动词 / 名词 / 地点）
- **there be 特殊**：先高亮数量/最近名词，再显语法标签（一个用 is、多个用 are）
- 分级：L1 单复数 -> L2 不可数 -> L3 就近原则

## 拖拽兜底（重要）
- 低龄（3-6）或触控不便：**必须有点选替代**（点 token -> 点 slot 入位），不强制拖拽
- 拖拽用 pointer 事件（pointerdown/move/up），兼容鼠标 + 触摸；不要只用 HTML5 drag（触摸不可用）

## 反馈教学性（字段化）
- 错误反馈**字段化**：标出哪个槽位错（谁 / 做什么 / 在哪里 / 单复数），给规则线索
  - 例：「单复数槽位错了：这里有两个苹果，应该用 are」
- **禁止**「错了 / 再想想」无信息反馈
- 正确：肯定 + 句子结构说明
- 答对全部 -> tada 庆祝 + 下一题

## 视觉一致与反馈动态（重要）
- **所有 token 外观必须一致**：禁止用颜色/灰度/样式区分答案与干扰项。干扰项的「意义」在于被认真考虑，而非被视觉排除。孩子凭颜色选对 = 核心认知任务被绕过（阻断项）。
- **错误确认语必须动态**：读取用户实际填入值生成确认语；空位时说「这个位置还没填」；跨类错放（名词放进 be 槽）须点出实际放入的词。禁止硬编码「你放了 X」。
- **错放后果可视化 + 重选引导**：放错时用对比图呈现「为什么错」（如单复数：画 1 个苹果标 is / 2 个苹果标 are；时态：画“经常”时钟 vs “此刻”动作），配三段式，然后**允许取出重放**（不锁死），一步步引导到正确。错误是引导起点，不是终点。
- **多题闭环**：全部完成后须有「重新开始」入口重置 qIdx=0；末题隐藏「下一题」按钮；进度条按已完成题数计算可达 100%。
- **互斥判定态清除**：复用槽位的判定态类（filled-correct/filled-wrong）在每次重新填入前必须显式 `classList.remove` 清除，禁止依赖 render 重置；建议用单一 `data-state` 属性驱动样式杜绝类累积。必测「错答->改正」场景验证红->绿切换。

- **错误反馈线索引导**：wrongHint 须给引导而非直给答案。模板：「确认行为(你放了X) -> 差异(名词是Y只/不可数) -> 线问(那该用is还是are呢?)」，禁止 wrongHint 直接写「应该用 is」。
- **fillSlot 状态回收**：覆写 slot 前须释放旧 token 的 used/picked 状态（读 filled[slotId] 旧值 -> 对应 token remove picked），保证词块可回收复选。

## 正确性
- `solution` 必须正确（slotId -> 正确 tokenId）
- 干扰项要有意义（同词性 / 近形 / 常见错配），不是随机
- 多组例题覆盖该知识点典型句型

## drag-slot 验收 checklist（生成后 read 回读逐条确认）
- [ ] 槽位+词块齐全，solution 正确，含干扰项
- [ ] 拖拽触摸可用 + 点选兜底
- [ ] 实时句子预览 + 即时判定（对/错视觉区分）
- [ ] 错误反馈字段化（标出错在哪 + 规则线索）
- [ ] 检查/重置/下一题可用；触控 ≥44px
- [ ] 多组例题；分龄分级
- [ ] 无外链、原生 JS 无库、单文件

## 常见失败
只用 HTML5 `draggable` 无 pointer/点选 → 触屏不可用；只拖不判/判了不反馈；干扰项随机无意义；wrongHint **直给答案**（如「应该用 is」）；反馈只说「错了」；单复数/就近原则讲错；触控太小；只有一组题无下一题/进度；token 用颜色泄题。

## 低龄分类也可用 drag-slot
3–6 岁：颜色/形状分类进「盒子槽」，大触控、点选优先、对错可取出重放。
