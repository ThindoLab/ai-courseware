# 参数图解教具创作（直出 HTML）

> 本 skill 是 **param-visual 类型专属**指导。通用分龄/方法论/动画清单见系统注入的通用规范。两者叠加生效。

## 你产出什么
一个单文件 HTML 参数图解教具，用 `write` 工具写入输出路径。不输出 JSON、不调模板渲染。

## 类型定位
数学/科学「参数关系」类：鸡兔同笼、和倍差倍、相遇行程、植树、平均数、盈亏、周长面积、分数、比例。
**核心**：用图呈现对象与算法规律，不只给算式。孩子拖滑块 -> 看到图、数、结论同步变化 -> 理解关系。

## 必须有
- ≥2 个滑块（可调参数），数值徽章醒目、拖动时 jello 跳动
- 主图区：**图解数学 diagram**（见下），随参数实时更新
- 结论区：随参数实时更新（如「鸡 {{n}} 只，兔 {{m}} 只」）
- ↻ 重置按钮
- 「我怎么想」叙述句（随交互变化）

## 图解数学（diagram）— 本类型灵魂
数学/计数/规律类**必须用 SVG 自绘 diagram**，不要只甩 icon-grid emoji。
1. **画出对象特征**：鸡=头+2腿，兔=头+长耳+4腿；头和脚都看得见。
2. **呈现算法规律**（以鸡兔同笼假设法为范式）：
   - 先画「假设全是鸡」一排（每只 2 腿）-> 标注「假设全是鸡，共 {{2×头}} 条腿」
   - 高亮「多出的腿」`{{腿-2×头}}`（换橙色）-> 每 2 条换 1 只兔（部分鸡换成兔，兔多 2 腿用不同色）
   - 最终呈现 `{{鸡}} 鸡 + {{兔}} 兔`，点出规律「每多 1 只兔，腿多 2」
3. 数值一律用 JS 实时计算注入 SVG（**不要写死**），拖滑块时图解实时变。
4. SVG：含 viewBox 自适应；只用原生图形（circle/rect/line/path/polygon/text）；禁止 `<image href=外部>`；**`<text>` font-size ≥16px**（与正文同下限，图解标注不得用 14px）。

## 各子题型图解选型
- 鸡兔同笼/和倍/假设法 -> **diagram 假设法三态**
- 相遇行程 -> **diagram** 道路线段 + 两 emoji 人物 + 箭头 + 距离/速度标注，人物位置随滑块移动，标相遇点
- 植树 -> **icon-grid** 🌳 沿线排列，对比两端都种/一端不种/两端不种，段数与棵数关系随滑块变
- 平均数 -> **bar** 多柱 + 平均线（虚线高亮），动态搬移多余块
- 分数 -> **pie** 圆环切分（stroke-dasharray），分子/分母滑块，高亮占比
- 周长面积 -> **rect** 宽高滑块，面积按长×宽动态铺小方格计数，周长逐边高亮（区分「围一圈」与「铺满面」）

## 边界/异常值可达（重要，泛化）
滑块**不得**强制约束到只允许有解/常规值。必须允许孩子输入边界/异常值，触发**可教学的特殊状态**，让多状态可视化都可体验、错误三段式反馈可触发。按子题型：
- 鸡兔同笼/假设法：允许奇数腿/越界 -> 无解态（全鸡/混合/无解三态）
- 分数：允许分子>分母（假分数）、0、整体1 -> 假分数/0/整体状态
- 行程：允许速度0/相离 -> 不可达状态
特殊状态时 wobble/橙色文案提示，不崩。**可视化「为什么无解」**：用图解呈现错误原因（如鸡兔同笼腿数对不上：画出头的数量与腿数，标出多/少几条；分数分母为 0：标注「不能分成 0 份」），引导孩子调整参数。错误是引导起点，不是终点。

## 分数专属图解（pie + 纸条双表征）
- pie 圆环切分（stroke-dasharray）+ 等长纸条多表征，**视觉强制整体相同**（同样长纸条分同样多份）
- **假分数 >1 饼图失效**：饼图最多表示整体1，假分数须用第二张饼/数轴延伸/数值徽章主导，**禁止让 3/2 与 2/2 视觉相同**
- 比较两分数须**同屏并排**（双饼/双纸条/数轴同标），不能只靠单图切换+记忆
- 含「整体相同才能比较」反例（不同整体的 1/2 不可比）

## 假设法双方向（加分）
提供「假设全是鸡」/「假设全是兔」可切换变式，让老师对比两种假设方向讲解。**「我会说」复述必须随当前假设方向切换** solve/solveRabbit 并分支叙述，禁止硬编码单一方向。

## 数值正确（零容忍）
用独立纯函数推导期望答案，关键公式：
- 鸡兔同笼：`兔=(腿-2×头)/2`，`鸡=头-兔`；腿为奇数或超范围 -> 无解提示（wobble + 橙色文案），不崩
- 相遇：`相遇时间=距离/(速1+速2)`
- 平均数：`总和/个数`
- 周长面积：`周长=2×(长+宽)`，`面积=长×宽`（铺格计数验证）

写 JS 前在注释写出公式；自检 ≥3 例含边界（0、最大、无解）。

## 最小验收句（生成前 COT 必写，QA 复用）
写清：「操作 ____ 后，能看见 ____ 过程（位移/生长/均分/对比），从而理解 ____ 关系。」不成立则不得交付。

## 教学质量（先于工程 checklist）
- 理解难度 / 形象性 / 图解清晰（图承载关系）/ 逻辑一致 / 过程真动

## param-visual 验收 checklist（生成后 read 回读逐条确认）
- [ ] ≥2 滑块（或等价控件），拖动 -> 图解+数值+结论三同步
- [ ] 主图是 diagram 图解（非纯 icon-grid / 纯算式）；周期/规律须标出「重复小段」
- [ ] 假设法/规律有三态可视化（假设值 / 真实条件 / 差异量）
- [ ] 结论区实时更新；**滑块允许输入无解值**（奇数腿/越界/钱不够），无解态可触发三段式反馈，wobble 提示不崩
- [ ] ↻ 重置可用；**触控目标**（含 padding）分龄达标，所有 button 含 stepper ±
- [ ] 数值公式正确（独立函数 + ≥3 例自检）
- [ ] 「我怎么想」+「我会说」；动画禁用 linear 做数据位移
- [ ] 无外链、原生 JS 无库、单文件

## 常见失败
只给滑块不图解；icon-grid 装饰而非呈现规律；假设法只写文字无三态；结论不随滑块更新；无解时 NaN/崩溃；首屏甩公式无图解桥接；数值写死不随滑块变。
