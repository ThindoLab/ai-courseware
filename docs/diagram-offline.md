# 离线图解增强（调研结论）

产品约束：**单文件 HTML、离线、无 CDN**。教室白板 / 家庭平板要能双击打开。因此不能把 Three.js、GSAP、Lottie、外链 GIF/MP4 写进教具。

## 调研过、不采用（生成时）

| 方案 | 为什么不进教具 |
|------|----------------|
| Three.js / Babylon / model-viewer | 要外链或上百 KB 运行时；低龄立体用 CSS 3D 足够 |
| GSAP / anime.js / Motion | 缓动库，能抄关键帧语义，不必带库 |
| Lottie / GIF | 体积大、不可调参、reduced-motion 差 |
| D3 / Chart.js / Mermaid | 偏数据图，不是儿童过程图解 |
| `image_gen` / 视频 skill | 出的是位图或外链资源，不是可拖滑块的关系图 |

这些库的**手法**可以学（ease-out、stagger、粒子上限），写法要内联。

## HTML 展示类 skill（纪律可学，壳不要）

面向「怎么把一屏讲清楚」，不是「怎么出图」。写手落地处仍是 `pi/角色/图解.md`。

| 来源 | 吸收 | 明确不吸收 |
|------|------|------------|
| frontend-design | 一幕一个签名；结构只编码真顺序；写完删一件装饰；文案当界面（错误写怎么改） | 每份教具另起一套杂志字体；三套 AI 默认皮（奶油衬线 / 黑底酸绿 / 报纸细线） |
| 归藏网页 PPT | 动效跟语义走；固定槽；`min(vw,vh)` 且 vh ≥ vw×1.6 | WebGL、Motion One、Lucide CDN、瑞士无圆角、越大越细的 200 字重 |
| 归藏社交卡 | 内容形状选布局；一焦点；禁装饰 blob；警示行 / 竖向步骤 / 对照叠放；脚用 flex 不绝对定位 | 纸纹、全幅照片、信息图横幅、密度 ≥75% 的海报算法 |
| md2wechat | 模块不要堆；一幕至多一个主图、一句结论、一组操作 | 公众号 hero / verdict / CTA 卡片壳 |
| pptx 设计原则 | 每幕要有图；正文左对齐；不要标题下 accent 短线 | 商务图标圆、每页换一套版式当装饰 |
| xueai 动画规范 | 控件驱动时图+数+结论再加状态色；错误 shake+色+重选；token 才 15ms stagger | 打字机光标、BERT 热图、成人干扰模式 |
| gpt-image-2 步骤/对照/教学图 | 步骤 3–5 同形编号+连线；对照两槽同高；引线不交叉；低龄字短图大 | 位图信息图、便当格、工程菱形决策框当儿童主图 |
| hand-drawn-styles | 讲解用细线火柴人；学前用同一豆人换动作；token 用扁平色块；全画只点一件 accent 物；负向约束写在前 | 19 套生图配方、蜡笔/吉卜力/水墨/像素/纸雕/潮玩、image_gen、纸纹摄影感 |

## 采用（写进 `pi/角色/图解.md`）

| 能力 | 原生手段 | 典型知识点 |
|------|----------|------------|
| 2D 关系 | 内联 SVG，改 `x`/`cx`/`d`/`width` | 影子、分数扇区、行程 |
| 过程动画 | CSS `@keyframes` / `transition` / WAAPI | 切开、搬格、拉长 |
| 伪 3D | `perspective` + `rotateY`/`rotateX` | 正方体翻面、展开 |
| 粒子 | Canvas 2D ≤40 点 | 气态 / 蒸汽 |
| 无障碍 | `prefers-reduced-motion` 停循环，保留终态 | 全部 |

`qa_check` 会警告：没有 `<svg>` / `perspective` / `<canvas>`，或没有任何 motion。

## 写手怎么接到

教练派写手前要求 `read pi/角色/图解.md`。禁止 CDN 与只改数字。体积目标仍是整份教具大约 8–20KB 可读（复杂题可略超）。
