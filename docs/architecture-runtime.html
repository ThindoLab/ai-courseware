怎么读这张图

  • 人只填主题；代码决定走绿还是紫。
  • 绿路不调模型；紫路只负责把 HTML 写到磁盘。
  • 虚线框是附属能力：有代码，但不挡主路径。

和文字版文档的关系

  • 本页：给人一眼看懂运行时。
  • 架构说明：接口、环境变量、阶段对照。
  • 生成 vs 样例：什么时候秒回、什么时候新写。

踩过的坑（已写进代码）

  • 有的模型不调「写文件」→ 永远没产物。
  • 输出额度太小 → 只想不写。
  • 弱匹配 / 复用旧文件 → 输什么都一样。
