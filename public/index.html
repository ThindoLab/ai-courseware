    创作技能

    内置 + 创作者技能，Agent 按所选技能的指引创作（见使用说明 → 创作者 SOP）

    这是什么

    把「讲不清的知识点」变成可交互图解教具。服务中幼儿、家庭辅导、教室白板与培训巩固——目标是降低理解难度、看清关系与过程，而不是堆静态 PPT。

    三步生成

    1. 输入知识点，选内容模块（学习辅导 / 学前 / 安全生活 / 故事文化）
    2. 可选教具类型：自动匹配，或指定参数图解 / 选择分支 / 拖拽槽位
    3. 点「生成教具」→ 接近精品较快；新主题约 30–180 秒

    三种交互类型

    • param-visual参数图解 · 滑块调参 + 公式 + 图标可视化（数学 / 科学）
    • branch-story选择分支 · 情境决策树，错误路径有反馈（安全 / 童话）
    • drag-slot拖拽槽位 · 拖词块入位 + 校验（英语句型 / 拼音）
    每个教具都是单文件、无外链、离线可用、触控目标 ≥44px，适合白板触控。

    创作者扩展

    按标准格式在 skills/creator/<name>/SKILL.md 写工艺即可被扫描。排程在 pi/教练.md，岗位在 pi/角色/。

    质量保证

    单文件无外链、分龄触控、安全错误不可模仿；精品样例经多角色质检（理解难度 / 形象性 / 图解清晰 / 逻辑 / 过程动态）。生成后可自动做外链与触控等合规检查。
